# Employee salary

Administrators can open **Workspace → Employee salary**, choose a month, and open a teacher to set up salary and view attendance.

## Monthly rates (USD)

| Work sessions per workday | Base monthly salary |
| --- | ---: |
| One daytime session (4 hours) | $125.00 |
| Two daytime sessions (8 hours) | $250.00 |
| One evening session | $31.25 |
| Two evening sessions | $62.50 |
| Two daytime and two evening sessions | $312.50 |

Daytime and evening rates are additive. Each teacher's service start date establishes their increase anniversaries. Every three completed calendar months adds $5 to the **total monthly salary**, without multiplying the increase by the number of sessions. The increase repeats indefinitely. Calendar anniversaries clamp to the last day of shorter months.

The current month is assessed as of today; past months use their final day, and future months show an end-of-month preview. Payments cannot be recorded for future months. There are no automatic attendance deductions or partial-month prorations.

## Attendance and payments

Attendance uses the existing teacher daily records and session scans. The salary detail page includes a daily attendance form and links to the full attendance report. Daily totals count days, not individual session scans. Missing attendance is shown as **Not recorded**.

Saving work sessions configures salary; it does not mark salary as paid. To record a completed salary payment, enter its date and optional reference and explicitly confirm it was paid. This records an existing disbursement; it does not transfer money. One salary payment can be recorded per teacher per month. The server calculates the amount and checks that it matches the reviewed amount.

Each recorded payment preserves the work sessions, service start date, base salary, increase, total, recording administrator, and payment date. Subsequent profile changes leave those payment records intact. Existing student fee and expense ledgers are separate from this payroll history.
